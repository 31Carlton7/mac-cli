### Task 1: Core model + all three protocols + actions + mocks
Files: `Sources/Core/IWorkModels.swift` (IWorkDocInfo{name,path?,modified:Bool}, SlideInfo{number:Int,title}) + schema tests (~3); `Sources/KeynoteModule/{KeynoteStore,KeynoteActions,KeynoteModule}.swift`, same for PagesModule/NumbersModule; Package.swift (3 targets + 3 test targets; NOT MacCLI deps yet); tests per module (~8 Keynote incl theme resolution + export rules, ~7 Pages, ~8 Numbers incl cell-ref regex).
Protocols (exact):
```swift
public protocol KeynoteStore {
    func docs() async throws -> [IWorkDocInfo]
    func themes() async throws -> [String]
    func newDoc(theme: String?, savePath: String?) async throws -> IWorkDocInfo
    func addSlide(doc: String, title: String, body: String?) async throws
    func slides(doc: String) async throws -> [SlideInfo]
    func export(doc: String, format: String, path: String) async throws   // format: "pdf"|"pptx"
}
public protocol PagesStore {
    func docs() async throws -> [IWorkDocInfo]
    func newDoc(savePath: String?) async throws -> IWorkDocInfo
    func getBody(doc: String) async throws -> String
    func setBody(doc: String, text: String) async throws
    func appendBody(doc: String, text: String) async throws
    func export(doc: String, format: String, path: String) async throws   // "pdf"|"docx"
}
public protocol NumbersStore {
    func docs() async throws -> [IWorkDocInfo]
    func newDoc(savePath: String?) async throws -> IWorkDocInfo
    func getCell(doc: String, sheet: Int, table: Int, cell: String) async throws -> String
    func setCell(doc: String, sheet: Int, table: Int, cell: String, value: String) async throws
    func export(doc: String, format: String, path: String) async throws   // "pdf"|"xlsx"|"csv"
}
```
Actions: resolveDoc + export contract as above; Keynote theme resolution (case-insensitive against store.themes(), unknown → notFound listing sorted first 5); Numbers validates sheet/table >= 1 and cell regex `^[A-Za-z]{1,3}[0-9]{1,7}$` (badInput "Invalid cell reference '<c>'. Use A1 notation."); Pages set/append reject empty text; Keynote add-slide rejects empty title. Commit: `feat: add iWork models, protocols, and mock-tested actions`. Expect ~450.

### Task 2: Keynote scripts + store + command + wiring
Script shapes: docs → per-doc loop (`document i`) emitting `name FS pathOrEmpty FS modifiedText` (path via try `POSIX path of (file of d as alias)` else ""; modified via try `modified of d` else "false"); themes → per-item `name of theme i`; newDoc → `make new document` (+ `with properties {document theme:theme "<escaped>"}` when theme given) + optional `save doc in POSIX file "<escaped>"` + emit its doc record; addSlide → `tell document "<n>"` `set s to make new slide at end` then try `set object text of default title item of s to "<escaped>"` (+ body item when given) — wrap mutations in try→REFUSED; slides → per-slide loop emitting `slide number FS (try object text of default title item else "")`; export → `export document "<n>" to POSIX file "<path>" as <TOKEN>` where TOKEN is `PDF`/`Microsoft PowerPoint` (raw enum tokens, NOT quoted strings) wrapped try→REFUSED. Store maps records/sentinels (REFUSED→badInput "Keynote refused: <msg>"); command tree `docs,new,add-slide,slides,export` with confirmations (`created` emits doc record json||!quiet; `added`/`exported` via emitConfirmation, exported value = path). Doctor row NOT yet (Task 5). MacCLI dep + Mac.swift wiring for KeynoteModule only. Tests: scripts ~6 (incl enum-token-not-quoted assertion), store ~4, parsing ~3; osacompile all. Commit: `feat: add Keynote module`. Expect ~463.
