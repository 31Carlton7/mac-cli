### Task 1: Models + protocol + actions (mock-tested)

Files: `Sources/Core/FinderModels.swift`, `Sources/FinderModule/{FinderStore,FinderActions,FinderModule}.swift`, Package.swift entries, `Tests/CoreTests/FinderModelsTests.swift`, `Tests/FinderModuleTests/FinderActionsTests.swift`.

Models (exact):
```swift
public struct FinderItem: Codable, Equatable, HumanRenderable {
    public let path: String
    public let name: String
    public let kind: String
    public var humanLine: String { "\(path)  (\(kind))" }
}
public struct DiskInfo: Codable, Equatable, HumanRenderable {
    public let name: String
    public let capacityBytes: Int
    public let freeBytes: Int
    public let ejectable: Bool
    public var humanLine: String {
        let eject = ejectable ? "  [ejectable]" : ""
        return "\(name)  \(freeBytes / 1_073_741_824)G free of \(capacityBytes / 1_073_741_824)G\(eject)"
    }
}
```
Exact-string schema tests (2 models, sorted keys) + humanLine (~3 tests).

Protocol (exact):
```swift
public protocol FinderStore {
    func selection() async throws -> [FinderItem]
    func reveal(path: String) async throws
    func open(path: String) async throws
    func trash(path: String) async throws
    func disks() async throws -> [DiskInfo]
    func eject(name: String) async throws -> Bool   // false = unknown disk at eject time
}
```
FinderActions contract: `resolve(path:)` helper — trim, reject empty (badInput), expand `~` via NSString.expandingTildeInPath, make absolute against FileManager.default.currentDirectoryPath, then `FileManager.default.fileExists` else `MacError(.notFound, "No file or folder at <resolved>.")`; used by reveal/open/trash (pass RESOLVED path to store). `eject(name:)`: trim/reject empty; validate against `disks()` case-insensitively → unknown notFound naming `mac finder disks`; matched-but-not-ejectable → badInput "'<name>' is not ejectable."; then store call, false → notFound (vanished). `selection`/`disks` passthrough. ~10 actions tests (fidelity mock; include tilde-expansion and relative-path resolution assertions via a temp file). Commit: `feat: add Finder models, store protocol, and mock-tested actions`. Expect ~400.

### Task 2: Scripts + store + command + doctor + wiring

Files: `Sources/FinderModule/{FinderScripts,AppleScriptFinderStore,FinderCommand}.swift`, DoctorCommand.swift (+`automation:Finder`, com.apple.finder, hint "finder", after automation:Shortcuts), Mac.swift (import/register before doctor; abstract + "Finder"), tests: FinderScriptsTests (~5), AppleScriptFinderStoreTests (~4), FinderCommandParsingTests (~3).

Script shapes (behavior-defining):
- `selection()`: `set sel to selection` then `repeat with i from 1 to count of sel` — per-item `set it to item i of sel` (selection IS a list, item-indexing a list is fine; do NOT bulk-property over it) emitting `POSIX path of (it as alias) FS displayed name of it FS kind of it`, each field in try→"" guards. Empty selection → "".
- `reveal(path:)`: `reveal (POSIX file "<escaped>")` + `activate`, return "ok". `open(path:)`: `open (POSIX file "<escaped>")`, "ok". `trash(path:)`: `delete (POSIX file "<escaped>")` wrapped in try→`REFUSED:<msg>` (v4 pattern), else "ok".
- `disks()`: `set n to count of disks` then `repeat with i from 1 to n` with `disk i` per-item (ledger: no object-range as-list): `name FS capacity FS free space FS ejectable` — capacity/free `as text` (they're large reals; store parses via Double→Int), ejectable via try→"false".
- `eject(name:)`: try `eject disk "<escaped>"` → "ok"; `on error number errNum` → if -1728 (can't get disk) "NOTFOUND" else `REFUSED:<msg>`.
Store: parse records; disks numbers via `Int(Double(field) ?? 0)`; REFUSED → badInput "Finder refused: <msg>"; NOTFOUND → false (eject). warn noun "item"/"disk". Command: six subcommands; reveal/open/trash/eject confirmations via emitConfirmation (keys "revealed"/"opened"/"trashed"/"ejected", value = resolved path or disk name); selection/disks emit lists. Help: trash notes recoverability; module abstract notes "GUI-state module — use your shell for file operations". osacompile all variants. Commit: `feat: add Finder scripts, store, and mac finder subcommands`. Expect ~412.
